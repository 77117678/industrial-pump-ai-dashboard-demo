605A101 干燥酸泵 AI Agent 网页驾驶舱（离线回放版）

一、它是什么？
这是一个在 Windows 电脑本机运行的网页驾驶舱。浏览器显示页面，数据仍在本机 reports 文件夹中。它读取现有 CSV/TXT 分析结果，展示健康评分、历史决策回放、异常事件、节能机会和数据文件状态。

重要边界：
1. 当前版本是离线历史数据驾驶舱，不是工厂在线实时监控系统。
2. 不连接 PLC/SCADA，不向设备发送任何控制指令。
3. 候选异常并不代表已确认故障；理论节能量也不是现场实测节能。
4. 若未找到某个 CSV，部分页面会显示此前已知的项目汇总值，并明确提示文件缺失；请在“数据文件状态”页面核对来源。

二、安装方式（适合初学者）
1. 将本 ZIP 解压到：C:\Users\李琴香\pump_ai_real
2. 解压后应看到：C:\Users\李琴香\pump_ai_real\web_dashboard\app.py
3. 确保项目分析结果放在：C:\Users\李琴香\pump_ai_real\reports
4. 双击 web_dashboard 文件夹里的“启动网页驾驶舱.bat”。
5. 第一次启动需要联网下载 Streamlit 等 Python 软件包，请等待命令窗口完成安装。
6. 浏览器通常会打开 http://localhost:8501。如果浏览器没有自动打开，可手动在浏览器地址栏输入这个网址。
7. 使用期间不要关闭运行 Streamlit 的黑色命令窗口；关闭窗口会停止网页。

三、刷新数据
先运行你现有的分析脚本，生成最新的 CSV/TXT 并保存到 reports 文件夹。随后在网页左侧点击“重新读取数据”，驾驶舱会尝试读取最新文件。

四、主要页面
- 总览：项目阶段成果、主要 KPI 和决策类别统计。
- 决策回放：查看 V12 决策历史，并按决策/优先级筛选。
- 异常事件：查看 Realtime Agent 事件与历史异常候选。
- 节能分析：查看节能机会估算和候选事件明细。
- 健康趋势：查看健康评分历史变化。
- 数据文件状态：核对每个页面的数据来源、文件是否找到以及记录数。

五、常见问题
1. 双击后窗口提示找不到 Python：请确认 Python 可在命令行通过 python --version 运行。
2. pip 安装失败：确认电脑可以访问 Python 软件包源，再重新双击启动文件。
3. 页面提示 CSV 未找到：查看数据文件状态页面，并确认分析输出位于 pump_ai_real\reports，而不是 src 文件夹。
4. 页面打不开：确认黑色命令窗口仍在运行，再访问 http://localhost:8501。
5. 默认端口被占用：Streamlit 可能提示换用其他端口，请根据命令窗口显示的网址打开。

六、下一阶段建议
先让本机离线驾驶舱稳定运行，核对每个图表与 CSV 原始数据一致；之后再评估只读在线采集（例如从历史数据库或 SCADA 数据库读取）。上线前需要 IT/自动化工程师审核访问权限、网络隔离和数据安全。不要直接让 AI 控制泵启停或改变工艺设定值。
